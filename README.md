# 🌿 Greenly

A modern organic grocery website built with React.js and Tailwind CSS.

## ✨ Features

- Responsive modern design
- Product categories and filtering
- Shopping cart with LocalStorage
- Search interface
- Favorites
- Smooth animations
- Mobile navigation

## 🛠️ Built With

React.js · Vite · Tailwind CSS · JavaScript · Lucide React
